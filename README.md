# Perplexity Terminal — Setup Wizard + SSH helper

Dieses Repo enthält ein lokales Web‑Terminal mit Setup‑Wizard zur einfachen Konfiguration einer SSH‑Verbindung (IP, Port, Username, Auth‑Methode). Der Server kann SSH‑Keys generieren und eine Testverbindung durchführen.

Wichtig: Dies ist Demo‑Code. In Produktion darfst du keine privaten Schlüssel, Passwörter oder API‑Keys unverschlüsselt speichern oder ins Repo einchecken.

Schnellstart:
1. Node.js 18+ installieren
2. npm install
3. npm start
4. Öffne http://localhost:3000 oder http://<deine-lan-ip>:PORT (das Skript sucht freien Port)

Beim ersten Laden erscheint der Setup Wizard.
